# 可访问性检查表

## 视觉

- [ ] 正文与背景至少 4.5:1，大文本至少 3:1。
- [ ] 次级文字不是浅灰到不可读。
- [ ] 关键控件边界清晰，不依赖阴影。
- [ ] 语义状态配文字或图标，不只颜色。
- [ ] 深色模式单独验证对比度。
- [ ] 图片上文字有实色/遮罩底板。
- [ ] 字号支持系统放大，布局允许换行。

## 触摸与操作

- [ ] 点击目标至少 88rpx×88rpx。
- [ ] 相邻操作间距足够，危险操作不紧邻主操作。
- [ ] 不依赖 hover 才能发现功能。
- [ ] 手势操作有可点击替代。
- [ ] 没有必须快速连续操作才能完成的流程。
- [ ] 输入有足够时间，不用倒计时逼迫。

## 语义与读屏

- [ ] 页面标题和区块标题结构合理。
- [ ] 图标按钮有可读名称或 aria-label。
- [ ] 图片有替代文本，装饰图不干扰朗读。
- [ ] 表单输入有持续可见标签。
- [ ] 错误信息与字段关联，可被读出。
- [ ] 弹窗打开后焦点/朗读不落到背景。
- [ ] 阅读顺序与视觉顺序一致。
- [ ] 列表/标签页选中状态可被识别。
- [ ] 关键信息不只存在图片或颜色中。

## 动效

- [ ] 动画不阻塞任务，不无限循环干扰。
- [ ] 提供低动效路径，或在系统减少动态效果时降级。
- [ ] 动画不过快导致无法理解状态变化。
- [ ] 加载动画有文字说明，屏幕阅读器可知忙态。

## 表单

- [ ] 必填、选填、格式要求清楚。
- [ ] 错误文案说明如何修复。
- [ ] 多错误有摘要并可定位。
- [ ] 提交失败保留输入。
- [ ] 验证码/倒计时有辅助说明。
- [ ] 密码显示切换有可读名称。

## 内容与语言

- [ ] 使用用户能理解的语言，不堆技术术语。
- [ ] 不用恐吓、羞辱或诱导文案。
- [ ] 重要时间、金额、单位完整。
- [ ] 适老场景使用更大字号和更短流程。
- [ ] 隐私、权限和付费说明清楚。

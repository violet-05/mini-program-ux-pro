# 交互质量检查表

## 导航与返回

- [ ] 每个页面知道从哪里来、返回哪里。
- [ ] 系统返回、左上角返回、手势返回结果一致。
- [ ] 从分享、扫码、消息或不存在的栈进入时，返回有安全出口。
- [ ] TabBar 只占稳定一级区域，2–5 项（优先 3–4）。
- [ ] 切换 Tab 不叠加页面栈。
- [ ] 筛选、滚动、已选规格在返回后保留。
- [ ] 未保存表单返回前有提示或草稿。

## 操作与反馈

- [ ] 每个按钮/卡片有真实动作，没有“敬请期待”死按钮。
- [ ] 按下态、loading、成功、失败、禁用与取消状态齐全。
- [ ] 处理中的按钮锁定，防止重复提交。
- [ ] 删除、支付、清空等危险操作有确认或撤销。
- [ ] 失败后可重试，不丢失已填数据。
- [ ] 反馈出现的位置与范围匹配：字段错误不用 toast，页面错误不只 toast。

## 表单

- [ ] 标签持续可见，不只靠 placeholder。
- [ ] 输入类型、键盘类型、最大长度正确。
- [ ] 错误靠近字段并说明如何修复。
- [ ] 多错误有摘要并可定位。
- [ ] 首次提交前不过度报错，提交后聚焦首错。
- [ ] 必填/选填规则明确。
- [ ] 提交中按钮不可重复点击。
- [ ] 提交失败保留表单和文件选择。

## 加载、空与错误

- [ ] 首屏有骨架或局部加载，不是空白。
- [ ] 局部刷新不遮全屏。
- [ ] 加载有超时和退出方式。
- [ ] 空状态区分新用户为空、筛选为空、无权限和错误。
- [ ] 空状态有一个明确下一步。
- [ ] 错误说明影响与恢复方式。
- [ ] 断网和弱网下保留旧数据或提供重试。
- [ ] 不无限循环重试。

## 键盘与底部

- [ ] 输入框、提交按钮不被键盘遮挡。
- [ ] 固定底栏不遮挡最后一段内容。
- [ ] 底部栏在安全区域内且内容有占位。
- [ ] 键盘收起后焦点与页面位置合理。
- [ ] 聊天/表单切换字段时不跳错位置。

## 触摸与手势

- [ ] 可点击目标至少 88rpx×88rpx（工程基线）。
- [ ] 相邻图标/危险操作有足够间距。
- [ ] 视觉小图标通过 padding 扩展热区。
- [ ] 横向滑动、纵向滚动与弹窗手势不冲突。
- [ ] 长按功能有提示，不替代普通点击。
- [ ] 误触不会导致数据丢失。

## 分享、授权与隐私

- [ ] 分享按钮真实触发平台分享，失败/取消有结果。
- [ ] 分享卡标题、封面、路径可回到正确页面。
- [ ] 权限在具体任务前请求，说明用途。
- [ ] 拒绝权限后仍可浏览或使用替代路径。
- [ ] 敏感接口与隐私协议/撤回流程一致。
- [ ] 不使用默认勾选、诱导授权或循环弹窗。

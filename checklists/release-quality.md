# 发布质量检查表

- [ ] Master 设计系统存在，页面覆盖有理由。

- [ ] 组件状态与设计系统一致。
- [ ] 未出现“只改颜色没有改布局”的伪重构。
- [ ] 现有业务逻辑、路由、权限未被擅自改变。
- [ ] 新增页面已在 app.json/pages.json/app.config 注册。
- [ ] 分享路径、扫码路径、冷启动路径可访问。

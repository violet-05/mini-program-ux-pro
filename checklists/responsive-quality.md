# 响应式与设备适配检查表

- [ ] 320px 窄屏无横向溢出。
- [ ] 375×667 小屏首屏不丢失主任务。
- [ ] 390×844 主流全面屏布局正常。
- [ ] 414/428px 大屏内容不被无限拉伸。
- [ ] 平板/PC 小程序使用最大内容宽度和合理留白。
- [ ] 横屏（如支持）不出现底栏遮挡或固定布局崩坏。
- [ ] 折叠屏/分屏按目标平台范围检查。
- [ ] 顶部状态栏、刘海、胶囊不影响标题和返回。
- [ ] 底部手势区不覆盖按钮或最后一项。
- [ ] 超长中文标题可换行/截断到详情。
- [ ] 长英文、URL、数字不撑破卡片。
- [ ] 系统字号放大后按钮和标签仍完整。
- [ ] 图片保持比例，不同来源图片不破坏布局。
- [ ] 双列网格在窄屏不压扁价格和标签。
- [ ] 数据表格在手机上不强行横排桌面列。
- [ ] 横向分类标签有可滑动暗示且触控足够。
- [ ] 弹窗/抽屉最大高度可控，内容可滚动。
- [ ] 空/错/加载状态在各尺寸下不跳动。
- [ ] 真机验证而非仅开发者工具多机型预览。
- [ ] 记录实际测试的设备、系统、微信版本与基础库。

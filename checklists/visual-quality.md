# 视觉质量检查表

> 每条都应有实际证据。静态代码不能代替页面截图，截图也不能代替真机。

## 首屏与层级

- [ ] 首屏只有一个最优先的视觉焦点，和产品核心任务一致。
- [ ] 首屏任务在 375×667 与 390×844 下不需要无意义滚动。
- [ ] 用户能回答“这是什么、我现在能做什么、下一步去哪”。
- [ ] 主标题、价格/关键数字、主操作形成清晰顺序。
- [ ] 灰度截图后层级仍成立，不依赖颜色硬撑。
- [ ] 页面没有把多个运营模块做成同等权重。

## 字体与文本

- [ ] 正文不小于 28rpx（建议 30–32rpx），辅助信息不小于 24rpx。
- [ ] 字号层级数量受控，同类文本一致。
- [ ] 标题行数与长文本规则明确，截断后能查看完整内容。
- [ ] 行高适合中文阅读，长文不过密。
- [ ] 数字、金额、单位换行规则明确。
- [ ] 系统字号放大后没有严重截断或重叠。

## 颜色与对比

- [ ] 正文/背景、次级文字/背景达到至少 4.5:1。
- [ ] 关键控制边界可见，不只靠阴影。
- [ ] 语义状态不只靠红/绿，配合文字或图标。
- [ ] 品牌色不是随处可见的背景贴图。
- [ ] 深色模式有独立 token，不是简单反色。
- [ ] 图片上的文字有可读底板或遮罩。

## 布局与节奏

- [ ] 卡片、列表、分区、数据块不是同一种容器。
- [ ] 对齐基于稳定网格，而不是逐页魔法数字。
- [ ] 间距有节奏，section/card/inline 间距不混用。
- [ ] 圆角、边框、阴影属于同一套语言。
- [ ] 首屏之后的信息密度有变化，不持续疲劳轰炸。
- [ ] 空状态、错误状态、加载状态与正常态视觉一致。

## 图片与图标

- [ ] 图片容器比例稳定，加载前后不跳动。
- [ ] 图片使用正确的 mode/裁切，不拉伸。
- [ ] 失败图片有占位和替代文本。
- [ ] 图标来源统一，线宽、尺寸、圆角一致。
- [ ] 不用 Emoji 代替正式图标（除非品牌明确如此）。
- [ ] 关键信息不只存在于图片里。

## 反模板化

- [ ] 首页结构来自业务任务，不是“搜索+轮播+四宫格+三卡片”。
- [ ] 视觉选择能解释为什么适合这个产品类型。
- [ ] 不同页面有共享语言但不同任务节奏。
- [ ] 没有无理由渐变、玻璃、发光或大阴影。
- [ ] 只换颜色/加阴影没有冒充视觉重构。

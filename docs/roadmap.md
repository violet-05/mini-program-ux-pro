## 阶段 C：完整设计智能体

计划方向：

### C1. 微信开发者工具模拟器适配器（✅）

已实际实现并验证：

- 检测官方 `cli.bat`；
- 检查服务端口；
- 通过 CLI `auto` + `automator.connect` 连接；
- 打开真实原生小程序；
- 运行页面与交互；
- 截图；
- 收集 console.error 与未捕获异常；
- 保存 JSON 结果与 PNG。

实测环境：DevTools 2.02.2608070、基础库 3.17.4、390×844 模拟器；24/24 检查通过、9 张截图。

约束：

- 服务端口必须由用户手动开启；
- 截图仅开发者工具模拟器；
- 不把旧 automator `launch()` 当作当前 CLI 的稳定接口；
- 不把模拟器结果当真实设备结论。

### C1b. 真机 / 远程自动化（⬜）

仍需：

- iOS/Android 真机连接与权限；
- 真机键盘、音频中断、分享、性能；
- 远程设备矩阵与证据归档；
- 不伪造截图或设备结果。

### C2. 视觉审查适配器（⬜）

统一输入：

- 截图；
- 页面类型；
- Master 设计系统；
- 产品定位；
- 审查目标。

输出：

- 问题；
- 严重度；
- 证据；
- 修复；
- 置信度。

约束：

- 模型判断与程序测量分开；
- 不默认上传用户截图到远程服务；
- 未接入时不得声称自动审美理解。

### C3. 自动迭代（🟡→⬜）

已有工作流与最多 3 轮规则，尚未实现无人值守的代码修改/验证闭环。需要：

- 可回滚修改；
- 回归检查；
- 运行时证据；
- 用户授权范围。

### C4. 数据扩展

- 更多行业产品类型；
- 更多真实品牌/风格组合；
- 更多深色/适老/无障碍案例；
- 更严格官方文档版本跟踪；
- 中文同义词/停用词评估集；
- 检索相关性基准。

### C5. 平台扩展（⬜）

当前只做微信。未来若扩展：

- 支付宝/抖音小程序需独立平台规则；
- 不能把微信规则改名复用；
- 需独立测试和官方来源。

## 不做

- SaaS 平台；
- 未经核实的大规模数据集抓取；
- 直接复制参考项目数据；
- 用 AI 自动评分替代业务/真机验收；
- 自动大规模迁移用户技术栈；
- 默认调用外部 AI API。

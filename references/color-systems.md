# 色彩系统

## 色彩不是一组好看的颜色

小程序配色要回答：

- 品牌识别是什么？
- 页面背景和表面如何分层？
- 正文/次级文字是否可读？
- 主操作和危险操作如何区分？
- 成功/警告/错误如何不依赖颜色？
- 深色模式是否独立设计？
- 不同页面是否使用同一语义 token？

MPUX Pro 的配色数据包含背景、表面、主/次文字、品牌、强调、边框、语义色、使用场景和对比度说明。生成器会计算主要文字对的 WCAG 对比度。

## Token 分层

建议至少三层：

### 原始色

```text
--color-neutral-0: #FFFFFF
--color-brand-600: #A83A24
--color-error-600: #B3261E
```

原始色不直接在组件里使用，除非是极少数品牌资产。

### 语义色

```text
--color-background
--color-surface
--color-text-primary
--color-text-secondary
--color-brand
--color-on-brand
--color-border
--color-success
--color-warning
--color-error
```

语义色让深色模式和品牌调整不需要重写页面。

### 组件色

```text
--button-primary-bg
--button-primary-text
--input-border-focus
--card-border
```

组件变体由语义色派生，不在页面里硬编码。

## 对比度

WCAG 常用目标：

- 普通文本：至少 4.5:1；
- 大文本：至少 3:1；
- 非文本控件/焦点：至少 3:1（按适用标准）。

关键组合：

- 主文字 / 背景；
- 主文字 / 表面；
- 次级文字 / 背景；
- 次级文字 / 表面；
- 品牌按钮文字 / 品牌色；
- 错误按钮文字 / 错误色；
- 深色模式所有文字组合。

工具：`python scripts/validate_data.py` 会校验配色库中的主要组合；页面实际颜色仍需自行计算。

## 语义色

- 成功：完成、可用、正常；
- 警告：需要注意但未阻断；
- 错误：失败、不可恢复、危险；
- 品牌色：识别与主操作；
- 强调色：辅助选择，不应和品牌色同时争夺主操作。

语义色不能只靠颜色：

- 成功/失败加图标和文字；
- 涨跌加正负号/方向；
- 库存/名额加文字；
- 错误加具体原因。

## 深色模式

深色模式不是：

```css
background: #000;
color: #fff;
filter: invert(1);
```

需要独立定义：

- 背景/表面层级；
- 主/次文字；
- 品牌色在深色底上的对比；
- 语义色；
- 图片遮罩/降亮；
- 阴影改为亮度和边框；
- 输入框/弹窗/空状态；
- 第三方组件。

平台是否支持深色配置、CSS 变量和图片适配，需按目标基础库/框架验证。

## 颜色数量

一个页面通常应控制：

- 1 个品牌主色；
- 1 个辅助强调色；
- 成功/警告/错误语义色；
- 中性色阶；
- 图片自身的颜色不计入 UI 色板。

如果样式里出现十几个未登记颜色，通常说明 token 没被使用。

## WXSS/CSS 变量

CSS 自定义属性可以在部分小程序基础库使用，但不能假设所有环境都支持。生成器会：

1. 输出字面值 token 到 `MASTER.json`；
2. 生成 `tokens.wxss` / `tokens.scss`，并标注兼容性；
3. 建议关键组件使用构建期变量或字面值，不把 CSS 变量当唯一实现。

## 品牌与业务

| 业务 | 常见色彩倾向 | 需要避免 |
| --- | --- | --- |
| 电商 | 暖色、品牌色、清晰价格 | 彩虹促销、低价感过强 |
| 金融 | 深绿/蓝、克制 | 金色炫富、红绿唯一编码 |
| 音乐 | 深色、封面主导 | 灯光遮盖操作与歌词 |
| 健康 | 柔和绿/蓝 | 恐吓红、诊断暗示 |
| 农业 | 自然绿/土色 | 户外低对比、绿色代表一切 |
| 文创 | 纸色、墨色、文化母题 | 无授权符号、金色滥用 |
| 数据 | 中性底 + 语义色 | 颜色唯一编码、无单位 |

数据文件见 [colors.csv](../data/colors.csv)。

## 检查

- [ ] 主要文字/背景 ≥4.5:1；
- [ ] 深色模式单独验证；
- [ ] 语义色不只靠颜色；
- [ ] 品牌色不承担小号正文；
- [ ] 未登记硬编码颜色受控；
- [ ] 图片上文字有实色底板；
- [ ] 焦点/边框可见；
- [ ] 色板与风格、业务匹配。

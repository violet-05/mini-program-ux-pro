# 间距系统

## 基础单位

建议使用 8rpx 为基础节奏（在 750 设计宽下约 4px），常用间距为其倍数：

| Token | 建议值 | 典型用途 |
| --- | ---: | --- |
| space-1 | 8rpx | 图标与文字的内部微调 |
| space-2 | 16rpx | 小标签、紧密元素 |
| space-3 | 24rpx | 卡片内边距、列表行内间隙 |
| space-4 | 32rpx | 页面边距、标准分组 |
| space-5 | 40–48rpx | 区块内分组 |
| space-6 | 56–64rpx | 大区块间距 |
| space-7 | 80–96rpx | 首屏留白、品牌节奏 |

不是所有页面都使用同一套间距。信息密度高的看板使用更紧凑的 4–6 档，品牌/阅读页面可使用更宽松的上限。但同一项目内应有稳定 token。

## 页面边距

- 标准：24–32rpx；
- 高密度：20–24rpx；
- 品牌/阅读：32–40rpx，但需保证内容宽度；
- 大屏：限制最大内容宽度，避免无限拉伸。

页面边距不等于卡片内边距。内容应形成至少两级容器：

```text
页面 gutter → 区块 → 卡片 → 内容
```

## 垂直节奏

- 正文行高决定基础节奏；
- 标题与正文之间 8–16rpx；
- 卡片内段落 16–24rpx；
- 区块之间 40–64rpx；
- 首屏主任务与顶部导航之间 24–48rpx。

常见错误：

- 所有间距都 20rpx；
- 卡片外边距 0 内边距 60rpx；
- 标题与正文距离大于区块间距；
- 空状态插画占满屏幕，按钮被推到底部。

## 密度

| 密度 | 页面边距 | 区块间距 | 卡片间距 | 适用 |
| --- | ---: | ---: | ---: | --- |
| 低 | 32rpx | 56–64rpx | 24rpx | 品牌、阅读、作品集 |
| 中 | 32rpx | 40–48rpx | 20–24rpx | 通用业务 |
| 中高 | 32rpx | 32–40rpx | 20rpx | 电商、列表 |
| 高 | 24rpx | 24–32rpx | 16rpx | 看板、企业工具 |

密度是业务决策，不是审美偏好。电商商品列表需要比较效率，农业监测需要户外可读性，作品集需要节奏和留白。

## 触摸与间距

- 触摸目标至少 88rpx×88rpx；
- 相邻可点击目标之间至少 16rpx；
- 危险操作与主操作之间至少 24rpx；
- 图标可视觉 32rpx，但热区要扩展；
- 不要用外边距缩小热区。

## 固定底栏与安全区

固定底栏需要：

```text
内容底部 padding ≥ 底栏高度 + 安全区
底栏 padding-bottom = 基础 padding + env(safe-area-inset-bottom)
```

示例：

```css
.bottom-bar {
  position: fixed;
  left: 0;
  right: 0;
  bottom: 0;
  min-height: 100rpx;
  padding-bottom: calc(16rpx + env(safe-area-inset-bottom));
  background: var(--mpux-color-surface);
}

.page-content {
  padding-bottom: calc(100rpx + env(safe-area-inset-bottom) + 32rpx);
}
```

CSS 变量和安全区能力需在目标环境验证。没有 CSS 变量支持时，使用生成的字面值。

## 圆角

- 小控件：4–8rpx；
- 卡片：8–16rpx；
- 大容器：16–24rpx；
- 胶囊：999rpx，仅用于真正的胶囊形态；
- 极简/瑞士/粗野：可接近 0。

不要让所有元素都使用同一个大圆角。圆角是风格语言的一部分，需要一致，而不是无处不在。

## 阴影

- 边框承担主要分区；
- 阴影只用于漂浮层/层级提升；
- 浅色背景避免黑色重阴影；
- 深色模式用亮度和边框；
- 低端设备避免大面积实时模糊。

## 布局网格

- 两列商品网格：列间距 16–24rpx；
- 服务宫格：4 列时每项热区足够，文字短；
- 分类侧栏：固定宽度 + 主内容滚动；
- 看板：12 栅格在手机上降为单列/双列；
- 设置：列表行，不用卡片堆叠。

## 检查

- [ ] 间距来自 token；
- [ ] 页面边距一致；
- [ ] 分组距离大于组内距离；
- [ ] 卡片内边距稳定；
- [ ] 固定底栏不遮挡内容；
- [ ] 触摸目标不被缩小；
- [ ] 大屏有最大宽度；
- [ ] 不同页面共享节奏但有任务差异。

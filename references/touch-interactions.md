# 触摸交互

## 手指不是鼠标

- 手指接触面积更大；
- 精确度更低；
- 会遮挡目标；
- 容易误触相邻控件；
- 移动中操作（走路/通勤）更困难；
- 手套、湿手、强光会影响。

微信官方设计指南建议点击物理尺寸约 7–9mm。工程上使用 **88rpx×88rpx（约 44px）** 作为热区基线，关键操作用更大。

## 热区与视觉尺寸

视觉图标可以 32–40rpx，但可点击区域要扩大：

```css
.icon-button {
  position: relative;
  width: 88rpx;
  height: 88rpx;
  display: flex;
  align-items: center;
  justify-content: center;
}
```

或用 padding/伪元素扩展，不影响视觉。不要通过 `transform: scale()` 缩小实际热区。

## 间距

- 相邻图标至少留 16rpx；
- 危险操作与主操作分开；
- 列表行整行可点时，内部小按钮要阻止冒泡；
- 一组操作超过 3 个时考虑 Action Sheet/更多菜单；
- 底部固定栏只放一个主操作。

## 按压反馈

原生小程序：

```html
<button hover-class="button-pressed" bindtap="submit">提交</button>
```

```css
.button-pressed {
  opacity: 0.88;
}
```

`hover-class="none"` 会移除按压态，除非有明确理由。自己用 view 模拟按钮时，要同时实现可访问名称、按压态和键盘/读屏语义。

## 滚动与手势

- 页面滚动与内部 scroll-view 只保留一个主滚动；
- `scroll-view` 必须明确高度和方向；
- 横向滚动有视觉提示；
- 长按操作不替代普通点击；
- 滑动删除需确认/撤销，且不与页面滚动冲突；
- 弹层打开时锁背景滚动。

## 输入

- input 高度足够；
- 清空按钮热区足够；
- 键盘类型正确；
- 焦点不突然丢失；
- 错误字段可定位；
- 键盘不遮挡。

## 防误触

- 删除/支付二次确认；
- 默认按钮不是危险项；
- 高频操作与危险操作分离；
- 提交后锁定；
- 表单未保存返回提示；
- 列表项与内部按钮事件隔离；
- 不使用双击作为唯一操作。

## 真机测试

- 用拇指，不用鼠标；
- 单手持机；
- 边缘、相邻按钮、列表末尾；
- 运动/弱光场景（如适用）；
- iOS/Android 不同触控反馈；
- 系统放大字体；
- 辅助功能。

## 检查

- [ ] 热区 ≥88rpx；
- [ ] 相邻间距足够；
- [ ] 按压态存在；
- [ ] 危险操作分离；
- [ ] 滚动不冲突；
- [ ] 键盘不遮挡；
- [ ] 真机手指测试；
- [ ] 不只依赖 hover/长按。

# 小程序排版

## 先使用系统字体

小程序正文优先使用系统字体：

```css
font-family: -apple-system, BlinkMacSystemFont, "PingFang SC",
  "Hiragino Sans GB", "Microsoft YaHei", sans-serif;
```

原因：

- 首屏不等待远程字体；
- 中文覆盖稳定；
- 系统字号/可访问性更好；
- 不增加包体和授权风险。

远程字体（如 `wx.loadFontFace`）只适合少量品牌标题，并必须：

- 确认字体授权；
- 限制字体子集/体积；
- 处理加载失败回退；
- 在真机检查布局跳动；
- 不让正文依赖远程字体。

## rpx 尺寸

WXSS 的 `rpx` 以 750 设计宽为基准。常见换算：

- 750rpx ≈ 屏宽；
- 28rpx ≈ 14px（375px 屏）；
- 30rpx ≈ 15px；
- 32rpx ≈ 16px；
- 44rpx ≈ 22px。

字号不要纯按比例缩放字体，否则小屏阅读困难。建议：

| 层级 | 建议字号 | 用途 |
| --- | ---: | --- |
| caption | 24rpx | 极短注释、角标 |
| meta | 26rpx | 时间、来源、辅助说明 |
| body | 30–32rpx | 正文、表单、说明 |
| body-lg | 34–36rpx | 重点正文、价格附近 |
| title | 40–44rpx | 页面/区块标题 |
| display | 48–64rpx | 品牌/数据焦点，慎用 |

具体比例由风格和产品决定，但正文不应低于 28rpx，辅助信息不低于 24rpx。

## 中文行高

- 正文行高：1.65–1.85；
- 长文阅读：1.75–1.9；
- 标题：1.25–1.45；
- 数字/价格：1.1–1.25；
- 标签/按钮：1.2–1.3。

中文没有英文单词间距，行高过低会明显拥挤。长文正文每行不要过宽；手机端通常自然满足，但大屏/平板需要限制内容宽度。

## 标题与长文本

- 首屏标题限制 2–3 行；
- 列表卡片标题限制 2 行，并提供完整详情；
- 页面标题不被系统导航截断到不可理解；
- 长英文/URL/连续数字要测试换行；
- 价格、库存等关键数字不省略；
- 关键信息不只存在于图片。

多行截断的 WXSS 支持与渲染引擎有关，使用前按目标环境验证：

```css
.title {
  display: -webkit-box;
  -webkit-box-orient: vertical;
  -webkit-line-clamp: 2;
  overflow: hidden;
}
```

如果目标引擎不支持，使用固定行数容器或服务端截断，并保留完整内容入口。

## 数字与价格

- 使用等宽数字特性（可用 `font-variant-numeric: tabular-nums`，按目标环境验证）；
- 货币符号、金额、单位同组；
- 小数位对齐；
- 原价、现价、会员价有层级；
- 不把价格做成图片；
- 大数字缩略（如 1.2万）时保留完整值入口。

## 字重

- 正文 400；
- 强调 500/600；
- 标题 600/700；
- 避免全站 300 细字；
- 深色背景上的细字更难读。

字体粗细的变化应有语义。不要用 5 种不同字重制造噪音。

## 字体与风格

| 风格 | 标题方向 | 正文方向 |
| --- | --- | --- |
| 极简/瑞士 | 系统无衬线，清晰层级 | 系统无衬线 |
| 编辑式 | 宋体/衬线标题 | 无衬线正文 |
| 现代东方 | 宋体标题 | 无衬线正文 |
| 年轻活泼 | 可用圆润/更粗字重 | 系统无衬线 |
| 数据密集 | 数字等宽，紧凑 | 系统无衬线 |
| 复古 | 粗衬线/印刷感标题 | 系统无衬线 |

不要因为风格名就加载一套不可用的中文字体。

## 适老与系统字号

- 不写死容器高度；
- 允许文本换行；
- 重要按钮/标签在大字号下仍完整；
- 关键正文至少 30–32rpx；
- 触控目标随字号适度增大；
- 在系统字号放大后重新测试首屏和表单。

## 检查

- [ ] 正文 ≥28rpx；
- [ ] 辅助 ≥24rpx；
- [ ] 标题行数受控；
- [ ] 行高适合中文；
- [ ] 数字/单位完整；
- [ ] 远程字体有回退；
- [ ] 系统字号放大不崩；
- [ ] 长文本/中英混合不横向溢出。

# 视觉层级

## 什么是好的层级

视觉层级不是“大标题 + 小字”，而是用户在 1–3 秒内按设计者意图完成扫描。它由以下因素共同构成：

- 尺寸；
- 字重；
- 颜色/对比；
- 位置；
- 留白；
- 图像；
- 动作与状态；
- 动效（最少使用）。

如果去掉颜色后层级崩塌，说明结构本身不够清楚。

## 首屏三问

用户进入页面时通常问：

1. 这是什么？
2. 我现在能做什么？
3. 下一步会发生什么？

首屏设计必须回答这三个问题。仅有漂亮图片和一句 slogan，不构成完整的产品首屏。

## 层级层级

建议一个页面最多三层主要视觉权重：

| 层级 | 内容 | 视觉策略 |
| --- | --- | --- |
| 一级 | 主任务/主信息/主操作 | 最大、最强对比、最先出现 |
| 二级 | 支撑决策的信息 | 中等字号、明确分组 |
| 三级 | 辅助/说明/元信息 | 小字号但仍可读、低对比但不隐形 |

“每样都重要”等于没有层级。

## 电商页面示例

商品详情：

1. 商品图片与商品名；
2. 当前价、关键规格、服务承诺；
3. 评价、详情、推荐；
4. 固定购买栏。

如果营销图占满首屏、价格在第二屏，层级就错位。

## 内容页面示例

文章详情：

1. 标题、作者/来源、时间；
2. 正文；
3. 图片说明与引文；
4. 收藏/分享/相关阅读。

如果广告卡和推荐位比正文更突出，内容优先失败。

## 数据页面示例

看板：

1. 时间范围与更新时间；
2. 3–5 个核心指标；
3. 趋势/异常；
4. 明细。

如果首屏是装饰性大标题和渐变，用户无法判断状态。

## 位置与扫描

手机常见扫描路径是 F 型/Z 型，但更重要的是业务优先级：

- 顶部适合上下文和主操作入口；
- 左上/大标题适合定位；
- 底部适合持续可用的单个主操作；
- 右侧适合次级动作，但不要堆叠小图标；
- 居中适合极短的空状态/结果状态。

不要把桌面端左右分栏直接缩成手机上下堆叠，任务顺序会变。

## 对齐与留白

- 使用统一页面边距（如 24/32rpx）；
- 卡片内边距一致；
- 标题与正文的间距大于正文行间距；
- 分组之间的距离大于组内元素距离；
- 关键操作周围保留呼吸空间。

留白不是越多越高级。它应该帮助分组和聚焦，而不是把核心信息推出首屏。

## 对比与可读性

- 主文字与背景至少 4.5:1；
- 次级文字仍达到 4.5:1；
- 大标题可 3:1，但不要依赖极浅灰；
- 关键控件的边界清晰；
- 主按钮与背景有足够对比；
- 错误/警告不能只靠颜色。

## 图片的层级

图片承担三种角色：

1. **内容**：商品、封面、作品 → 保证比例、清晰度和加载状态。
2. **识别**：头像、图标 → 保持尺寸和风格一致。
3. **氛围**：品牌横幅 → 不应挤掉任务，也不能让文字不可读。

装饰图不应该比商品图/正文更重要。

## 固定层的层级

固定底栏/导航必须：

- 不遮挡内容；
- 不覆盖平台胶囊；
- 有清楚边界；
- 只有一个主操作；
- 处理安全区和键盘；
- 不与弹层争夺 z-index。

## 审查方法

1. 灰度截图，眯眼 3 秒，标记最先看到的三项。
2. 对照业务优先级，检查顺序是否正确。
3. 移除颜色，检查字号/位置/留白是否仍可分层。
4. 在 375px 和 390px 宽度重复。
5. 检查加载/空/错/键盘状态。
6. 对每个“同级”模块询问是否真的同级。

## 常见错误

- 每个模块都加卡片和阴影；
- 标题字号多但层级少；
- 价格和销量同权；
- 主按钮与次按钮同色；
- 首屏全是运营位；
- 内容页广告比正文抢眼；
- 数据页没有主指标；
- 固定底栏遮住内容。

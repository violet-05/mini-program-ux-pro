# 粗野主义

## 核心意图

用硬边、高对比、超大字和暴露结构制造直接、原始、不修饰的表达。粗野不是忽视可用性。

## 视觉语言

- 硬边框；
- 纯色块；
- 超大字；
- 系统字体；
- 网格/结构外露；
- 刻意打破精致装饰；
- 黑白 + 一个警示色。

## 小程序适配

- 小屏超大标题容易溢出；
- 正文仍可读；
- 按钮热区不能因视觉粗粝而缩小；
- 深色模式必须对比；
- 布局在 320px 测试；
- 自定义导航/胶囊不要被覆盖。

## 排版

- 系统字体或超粗无衬线；
- 行距紧凑但可读；
- 大小标题有意冲突；
- 正文不用夸张字距；
- 长文本限制行数/提供详情。

## 颜色

- 黑白为主；
- 一到两个警示色；
- 不用柔和渐变；
- 对比足够；
- 语义色明确。

## 组件

- 直角/粗边框；
- 实体标签式按钮；
- 明显分割；
- 图片低处理；
- 交互状态清晰。

## 动效

- 0–120ms 或直接切换；
- 保留必要按压反馈；
- 不用平滑到失去粗粝感；
- 不做无限动画。

## 适用

- 先锋文化；
- 艺术活动；
- 独立品牌；
- 开发者工具；
- 实验作品集。

## 不适用

- 医疗；
- 儿童；
- 老年服务；
- 高信任商业；
- 复杂金融。

## 常见错误

- 以粗野为借口忽视对比/触控；
- 所有文字超粗；
- 边框堆叠导致噪音；
- 小屏溢出；
- 导航不清晰。

## 反模板策略

先确定结构与信息，再使用“粗野”作为语气。一个页面只保留一个强视觉动作。

## 检查

- [ ] 320px 溢出；
- [ ] 正文对比；
- [ ] 触控；
- [ ] 导航/胶囊；
- [ ] 字号层级；
- [ ] 色彩语义；
- [ ] 深色模式；
- [ ] 真机。

# 数据密集型

## 核心意图

让用户快速判断状态、发现异常并进入处理。它不是“多放几个图表”，而是信息密度、单位、时间范围和层级的秩序。

## 视觉语言

- 紧凑网格；
- 数字优先；
- 稳定列宽；
- 筛选/更新时间清楚；
- 语义色；
- 图表为解释服务。

## 小程序适配

- 手机首屏只放 3–5 个核心指标；
- 不把桌面表格压缩；
- 图表单位/图例；
- 筛选面板安全区；
- 固定操作不遮数据；
- 原生组件/canvas 层级。

## 排版

- 数字等宽；
- 标签紧凑但≥24rpx；
- 单位/时间范围紧邻数字；
- 避免长说明；
- 表格右对齐。

## 颜色

- 中性背景；
- 品牌色用于交互；
- 数据使用语义色；
- 正负值配符号；
- 不只靠颜色；
- 深色模式独立。

## 组件

- 筛选条；
- 分段控制；
- 表格/列表；
- 图表；
- 异常列表；
- 更新时间；
- 导出。

## 动效

- 100–180ms；
- 局部刷新；
- 不全屏闪烁；
- 数据变化有明确提示；
- 加载/错误清楚。

## 适用

- 数据看板；
- 企业管理；
- 智慧农业；
- 智能硬件；
- 金融账户；
- 运营后台。

## 不适用

- 品牌故事；
- 沉浸音乐；
- 亲子内容；
- 奢华留白首页。

## 常见错误

- 所有指标一样大；
- 环形图滥用；
- 没有单位/时间范围；
- 颜色唯一编码；
- 手机首屏塞 20 个指标；
- 图表无空状态。

## 反模板策略

先确定决策问题（今天发生了什么？哪里异常？），再选择 3–5 个指标和一个趋势。其余信息进入下一层。

## 检查

- [ ] 核心指标≤5；
- [ ] 单位/时间；
- [ ] 图例/颜色；
- [ ] 图表空/错；
- [ ] 筛选/重置；
- [ ] 固定操作不遮；
- [ ] 低端机；
- [ ] 真机。

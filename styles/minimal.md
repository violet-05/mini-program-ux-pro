# 极简主义

## 核心意图

让任务、内容和层级成为主角。极简不是“白底灰字”，而是减少无意义元素后仍保持清晰和品牌识别。

## 视觉语言

- 大面积留白；
- 少量颜色和分隔线；
- 精确对齐；
- 一个视觉焦点；
- 强烈但克制的字号层级；
- 阴影极少或没有。

## 小程序适配

- 首屏仍要回答“这是什么、能做什么”；
- 不要把主任务推到第二屏；
- 正文不小于 30rpx，辅助不小于 24rpx；
- 深色模式下不必纯黑，保留表面层级；
- 固定底栏与安全区正常处理。

## 排版

- 系统无衬线；
- 5–6 级字号；
- 标题通过字重/间距分层，不用过多字体；
- 数字使用等宽特性（按环境）；
- 长标题仍提供完整入口。

## 颜色

- 中性背景 + 一个品牌色 + 一个强调色；
- 避免低对比灰字；
- 语义色仅在必要时出现；
- 深色模式独立 token。

## 组件

- 边框少而细；
- 按钮：实心主按钮 + 文字次按钮；
- 卡片只用于需要独立比较/整体点击的内容；
- 图标线性、统一线宽；
- 表格/列表可用于替代卡片。

## 动效

- 100–180ms；
- 只用于状态和空间关系；
- 不做无限装饰；
- 页面切换不叠加多层入场。

## 适用

- 工具；
- 个人记账；
- 设置；
- 金融/专业工作台；
- 内容阅读；
- 会员中心；
- 高端品牌基础层。

## 不适用

- 需要强氛围的音乐/活动；
- 儿童/亲子；
- 需要高密度实时数据的场景（可用但需专门处理）；
- 强促销电商主会场（可做高级子页）。

## 常见错误

- 把极简做成空旷；
- 所有元素低对比；
- 卡片全白，层级消失；
- 每个模块都留超大间距；
- 没有主操作。

## 反模板策略

问：如果移除所有品牌色和阴影，页面是否仍有明确结构？如果答案只是“白底文字”，说明结构没有被设计。

## 检查

- [ ] 首屏一个焦点；
- [ ] 主任务可见；
- [ ] 对比度；
- [ ] 正文/辅助字号；
- [ ] 留白不挤压任务；
- [ ] 组件不是全套卡片；
- [ ] 深色模式；
- [ ] 真机键盘/安全区。

# 现有项目审查工作流

## 核心原则

审查不是重写。默认只读；未经用户明确授权，不修改业务逻辑、路由、支付、权限或技术栈。

## 1. 明确审查授权

先确认用户要：

- 只审查并给建议；
- 审查后修 UI；
- 审查并修复交互/平台问题；
- 只改一个页面或组件。

用户只要求“看看/为什么普通/检查一下”时，输出发现和建议，不直接改代码。

## 2. 识别项目

```bash
python scripts/audit_mini_program.py --path . --format json --output review-before.json
```

先看：

- 技术栈识别是否与实际项目一致；
- 页面声明与页面文件是否匹配；
- 是否检测到设计系统；
- 未执行的环境。

未识别技术栈时，先读项目配置和依赖，不要凭文件后缀猜。

## 3. 保护现有内容

在修改前：

- 不删除已有页面；
- 不改变入口路由和 TabBar，除非确认导航问题；
- 不替换 UI 框架；
- 不把 uni-app/Taro 改写为原生，反之亦然；
- 保留现有 API、状态管理和业务逻辑；
- 优先复用现有组件和 token；
- 单次改动范围小且可回滚。

## 4. 静态审查

工具会检查：

- 页面模板/路由完整性；
- TabBar 数量和图标；
- 自定义导航/胶囊；
- WXML 浏览器标签和事件；
- 浏览器 API；
- 安全区/固定底栏；
- 触摸目标和字号；
- 加载/空/错误状态；
- 图片、隐私、token、列表 key。

工具不能检查实际视觉、键盘、性能、分享和真机行为。报告中的 `verification` 字段必须保留。

## 5. 页面级审查

按任务路径走：

1. 首页；
2. 核心任务入口；
3. 列表/详情；
4. 表单/支付；
5. 结果/空/错；
6. 返回/分享回跳。

阅读 `MASTER.md` 与页面覆盖，比较实际页面是否遵循。没有 Master 时先记录现有 token 与组件语言。

## 6. 视觉与交互审查

- 视觉：首屏焦点、层级、字号、密度、对齐、图片、色彩、组件一致性。
- 交互：点击反馈、表单、加载、空、错误、键盘、底栏、返回、授权、分享。
- 平台：导航、TabBar、安全区、原生组件、真机差异。

需要截图时，标注是开发者工具、浏览器还是真机。没有截图/真机就不声称视觉或真机通过。

## 7. 问题分级

- **P0**：页面不可用、路由不存在、核心功能失效、代码在微信目标直接报错。
- **P1**：安全区遮挡、导航不可返回、键盘遮挡、支付/表单不可完成、严重对比或触摸问题。
- **P2**：状态缺失、层级不清、token 不一致、隐私提示缺失、严重长文本问题。
- **P3**：细节、可读性优化、多余装饰。

每个问题需要：证据、影响、建议、涉及文件、判断方式和置信度。

## 8. 形成修复计划

先修 P0/P1；P2 在不破坏业务的前提下处理；P3 最后。每项写明：

- 修改文件；
- 修改范围；
- 验证方法；
- 回滚方式（必要时）；
- 是否改变业务逻辑（默认不允许）。

## 9. 修改后复查

修改前先保存基线：

```bash
python scripts/audit_mini_program.py --path . --format json --output review-before.json
```

修改后重新审查并比较：

```bash
python scripts/audit_mini_program.py --path . --format json --output review-after.json
python mpux.py compare review-before.json review-after.json
```

对比报告区分新增、新增待确认、已确认修复、无法确认和遗留。`unconfirmed` 表示本次没有执行同一检查或扫描范围缩小，不能算修复；`new_unverified` 表示问题所在文件或检查上次没有覆盖，不能直接归因为本次引入。仍需人工确认：

- 页面是否仍能返回和完成核心任务；
- 新增颜色/圆角/组件是否遵守设计系统；
- 未重新验证的项是否被误报为通过。

## 10. 输出报告

使用 [审查报告模板](../templates/review-report.md)，至少包含：

- 项目/技术栈/页面/设计系统版本；
- 检查环境；
- 已执行与未执行检查；
- 分级问题与证据；
- 修改计划；
- 复查结果；
- 未完成项。

## 禁止

- 借 UI 优化之名重写业务。
- 改完不复查。
- 删除现有功能来让页面“更干净”。
- 把自动审查结果直接当成真机验收。
- 未经授权规模化替换技术栈。
